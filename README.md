# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website built using **React** and **Vite**.  
This website showcases your **projects**, **skills**, and **experience** with a clean, minimal, and interactive UI.

---

## 🚀 Features

- ✅ Fully responsive design (desktop & mobile)
- 🎨 Modern UI with smooth interactions
- 🧩 Project showcase with **Live Demo** & **GitHub Links**
- 🧑‍💻 About section with skills & experience
- 📩 Contact form (email integration-ready)
- ⚡ Super-fast build & development with **Vite**
- 🌍 Easy hosting on **GitHub Pages / Vercel / Netlify**

---

## 🛠️ Tech Stack

| Category            | Technology                      |
| ------------------- | ------------------------------- |
| **Frontend**        | React + Vite                    |
| **Styling**         | CSS / Tailwind CSS (optional)   |
| **Deployment**      | GitHub Pages / Vercel / Netlify |
| **Version Control** | Git & GitHub                    |
